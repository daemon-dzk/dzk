# Changelog

## [0.1.1] - 2026-09-09
### Added
- `dzk dns` - DNS query module (A, AAAA, MX, NS, TXT, CNAME)
- `dzk http` - HTTP/HTTPS analyzer (headers, cookies, SSL certs)
- `dzk pcap` - PCAP analyzer (protocols, top talkers, suspicious detections)
